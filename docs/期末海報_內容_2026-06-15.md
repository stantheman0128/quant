## 1. Motivation（研究動機）　← 對應評分 20%

- 台股散戶佔成交量約 **50%**，且大量散戶跟著財經 KOL 進出，KOL 是影響散戶決策的重要訊息源。
- 過去研究覆蓋紙媒投顧、機構分析師、電視投顧；**獨立、未受監管的網路財經 KOL 相對未被探索**，且無客戶／監管利益污染 —— 是相對乾淨的測試樣本。
- KOL 發文是**自由文本**，下游量化無法直接使用。
- **挑戰／範圍收斂**：我們不試圖量化 KOL 對市場的因果「影響力」（因果難以乾淨識別），改為把 KOL 觀點當成一個**選股因子**來檢定。
- **核心問題**：把 KOL 做成因子後，在扣掉已知價量因子（Alpha101）之後，它還有沒有預測力？
  ＝ 帶來新資訊，還是只是動能的重新包裝？

## 2. Method / 系統流程（方法）　← 對應評分 40%（可行性 + 創新）

### 2.1 Pipeline（給流程圖用）

```
KOL 貼文(FB) → LLM-as-Formatter → 4 欄位 Schema → 每日 KOL 因子 f_kol → 移除 Alpha101(正交化) → Incremental IC
```
- 資料來源：FB 財經 KOL 貼文（爬蟲）＋ 台股／美股 OHLC。
- 註：`weight` = 該 KOL 發文「之前」的 walk-forward 歷史命中率（point-in-time，防 look-ahead）；`direction` 由 LLM 抽取。

### 2.2 四個步驟

1. **LLM-as-Formatter・不評分**：自由文本 → 4 欄位 schema；LLM 只做格式化 + 實體消歧（台積 ≡ 2330 ≡ TSMC），不輸出信心分數。→ 避開「LLM confidence 不可靠」問題。
2. **Walk-forward 權重・point-in-time**：`weight` = 該 KOL 在該則發文「之前」的歷史命中率；最少 30 筆才估、不足給 0.5。→ 嚴防 look-ahead bias。
3. **聚合成每日 KOL 因子**：對每檔股票彙總近期 KOL 訊號，得到橫斷面因子 `f_kol`。
4. **Incremental IC vs Alpha101・核心**：見第 3 節。

### 2.3 核心 schema（每則 KOL 觀點抽成 4 欄位）

```json
{ "timestamp": "2026-03-15T09:00:00+08:00",
  "id": "2330",
  "direction": +1,          // -1 空 / 0 觀望 / +1 多
  "weight": 0.65 }          // walk-forward 歷史命中率
```

## 3. Incremental IC vs Alpha101（核心方法）　← 40% 的關鍵

### (a) 為什麼　Why
KOL 常被質疑「只是追動能」。動能是 Alpha101 早已涵蓋的已知因子。Incremental IC 問的是：**扣掉 Alpha101 已知的東西後，KOL 因子還剩多少預測力？**
- 剩 → 帶來價量看不出的**新資訊**。
- 不剩 → 只是**動能的重新包裝**（誠實的 null result）。
→ 把「是不是別人／動能做過了」變成一個**可被證偽的數字**。

### (b) 怎麼做　How（每個 rebalance 日・橫斷面）
1. 取 KOL 因子 `f_kol` 與 Alpha101 因子 `A₁…Aₖ`。
2. 橫斷面迴歸 `f_kol ~ A₁…Aₖ`，取殘差 `e`（Alpha101 解釋不掉的部分）。
3. `Incremental IC = corr( e , 未來報酬 )`，逐日平均。
4. 比較 raw IC 與 incremental IC；落差越小 → KOL 越獨立於價量。
5. 加 **Deflated Sharpe** 校正多重檢定。
- **目標**：incremental IC ≥ 0.03（baseline）／≥ 0.05（stretch）。

## 4. Experimental Results（實驗結果）　← 對應評分 40%

**PoC：3 位 FB KOL ・ 1,685 觀點 ・ 404 標的 ・ 2024–2026**

**表 1. 三種訊號策略比較**（C ＝品質壓倒數量，Sharpe 最佳）

| 策略 | hit rate | IC | Sharpe |
|---|---|---|---|
| A 純方向 | 54.3%（p=0.003） | +0.045 | +1.11 |
| B walk-forward 加權 | 55.0% | **+0.097（×2.1）** | +0.97 |
| **C 高信心過濾（weight>0.55）** | **57.9%** | — | **+1.65 ★** |

**表 2. Walk-forward 權重分位的命中率**（49% → 62% 單調遞增，證明權重有預測力）

| weight 分位 | n | hit rate |
|---|---|---|
| < 0.45 | 276 | 49.3% |
| 0.55–0.60 | 271 | 55.0% |
| **> 0.60** | 180 | **62.2% ★** |

> ⚠ **誠實註記**：上表為 raw IC（pooled），**尚未扣 Alpha101**；incremental IC（核心驗收）計算進行中。

## 5. Our Ideas / 定位（重點）

- **把「KOL 是不是只是動能」變成可證偽的數字。** Incremental IC vs Alpha101 直接量測 KOL 因子在已知價量因子之上的增量。
- **職責分離 + 防 look-ahead。** LLM 只格式化、評分外部化給歷史 walk-forward；把 KOL 當「因子」而非量化「影響力」，使結論可嚴格回測。
- **定位（誠實）。** 方法（factor orthogonalization、WFA）是標準量化；新意在**樣本 —— 繁中獨立 KOL —— 與把這套嚴謹度帶進這個少有人做的領域**。指導教授已認可「把既有方法搬到沒人做的乾淨樣本」此路徑。
- **已浮現的訊號結構（PoC 4 個 anomaly）**：KOL skill 不跨市場、過度自信反而較差、被當「反指標」者實為延遲跟隨、多空 skill 不對稱（→ 之後分 `weight_long / weight_short`）。
