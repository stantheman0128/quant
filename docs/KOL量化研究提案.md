# KOL 量化情緒因子研究提案

**作者**：施博瀚（Stan Shih）  
**日期**：2026-04-14  
**定位**：量化研究專案 — 另類數據因子方向探索

---

## 一、我們要做什麼、怎麼做

### 核心概念

建立一套**多 KOL 跨平台情緒量化系統**：持續追蹤台灣財經 KOL（Key Opinion Leaders）在 Threads、X（Twitter）、YouTube 等平台上的投資言論，用 LLM 自動提取其操作立場，並將這些行為轉化為可回測的量化因子。

### 技術架構

```
【資料蒐集層】
各平台爬蟲（Apify / API）
Threads · X · YouTube 字幕 (Whisper)
         ↓
【語義提取層】
LLM 分析（Traditional Chinese NLP）
提取：標的名稱 · 操作方向 · 信心程度 · 情緒強度
         ↓
【因子建構層】
KOL 情緒訊號 → 量化因子
單 KOL 方向因子 · 多 KOL 聚合因子 · 反指標因子
         ↓
【回測驗證層】
Walk-Forward 回測 + Alpha101 多因子整合
Sharpe Ratio · IC · 因子衰減分析
```

### 三類因子設計

| 因子類型 | 邏輯 | 範例 |
|----------|------|------|
| **正向跟隨因子** | 跟隨高準確率 KOL 的方向做 | 某 KOL 歷史勝率 > 60%，跟著做 |
| **反向指標因子** | 對「反指標 KOL」做反向操作 | 巴逆逆買入 → 做空訊號 |
| **共識聚合因子** | 多 KOL 同時看多/看空時，信號聚合 | 3 個以上 KOL 一致看多 → 強多訊號 |

## 二、為什麼要這樣做

### 市場情緒的資訊不對稱

散戶的群體行為早於被定價進市場之前，存在短暫的可交易視窗。KOL 在台灣具有龐大追隨者，其言論對散戶行為有直接影響，但這個影響目前沒有被系統性量化過。

### 現有研究的缺口

| 現有研究 | 缺口 |
|----------|------|
| Twitter 整體情緒 → 市場指數 | 太粗糙，沒有區分 KOL 個體差異 |
| Reddit r/WSB → 個股動量 | 英文市場，中文財經 KOL 幾乎無人研究 |
| 財經新聞 NLP | 媒體是落後指標，KOL 更即時 |
| 單一反指標追蹤 | 只追蹤單一人物，無法形成可泛化的因子框架 |

**核心洞察**：KOL 的預測品質本身就是一個可量化的特徵值。當我們知道某個 KOL 歷史上在特定市場條件下的勝率，就能動態調整對其訊號的信任度——這是現有系統完全沒有做的事情。

## 三、接下來打算怎麼做

### Phase 0（現在）：研究 + 驗證
- [ ] 研究 banini-tracker 開源架構，理解爬蟲 + LLM 提取的實作細節
- [ ] 選定 3–5 個初始 KOL（至少含一個「反指標型」、一個「正指標型」）
- [ ] 確認各平台資料可取得性（Threads API、X API 限制、YouTube 字幕）

### Phase 1（第 1–2 週）：資料管道建立
- [ ] 建立 KOL 貼文爬取管道（參考 banini-tracker 的 Apify 架構）
- [ ] 設計 LLM Prompt：提取標的、操作方向、信心程度
- [ ] 建立 SQLite schema：`kol_posts` + `predictions` + `price_snapshots`
- [ ] 用 FinMind 抓台股歷史價格，對應每筆預測的基準價格

### Phase 2（第 2–3 週）：因子建構與初步回測
- [ ] 計算每個 KOL 的歷史預測準確率（rolling window）
- [ ] 建立三類因子的計算邏輯
- [ ] 整合進現有的 Alpha101 回測框架
- [ ] 初步 Sharpe / IC 評估

### Phase 3（第 3–4 週）：壓力測試 + 穩健性
- [ ] Walk-Forward 驗證（避免過度擬合）
- [ ] 因子衰減分析：訊號在 T+1、T+3、T+5 各有多少 IC？
- [ ] 多 KOL 聚合效果驗證：合併信號是否優於單一 KOL？

### Phase 4（第 4–5 週）：報告與展示
- [ ] 撰寫研究報告（含方法論、回測結果、因子穩健性）
- [ ] 製作展示材料（Sharpe 曲線、KOL 準確率熱力圖）

## 四、希望達到什麼效果

### 量化指標目標

| 指標 | 目標 |
|------|------|
| **KOL 因子 IC** | 至少 0.03–0.05（有統計顯著性） |
| **整合多因子 Sharpe** | 優先目標 2.0+（面試基準線） |
| **預測追蹤筆數** | 每個 KOL 至少 50 筆可驗證預測 |
| **覆蓋標的** | 台股 + 主要 ETF，至少 30 個標的 |

### 研究成果目標

1. **對優式資本**：展示「另類數據 + 量化框架」的整合能力；這是目前主流量化基金正在追求的方向，顯示前瞻性思維
2. **對教授專題**：提供具有可重複性的研究框架；LLM + 中文財經 NLP + 因子回測是清晰的技術貢獻
3. **對長期發展**：這個系統可以持續運作，形成一個有實際預測價值的另類數據集

## 五、獨特性：為什麼沒人做過

### 學術上的突破

**目前沒有任何已知學術論文**針對以下組合做過研究：
> **中文財經 KOL 個體行為** × **跨平台追蹤** × **量化因子化** × **Alpha101 整合**

這四個條件缺一就是現有研究，但同時滿足就是空白地帶。

### 技術上的創新

| 傳統做法 | 本研究的突破 |
|----------|------------|
| 對 KOL 做二元情緒分析（正/負） | 精細提取操作狀態（買入/加碼/被套/停損）|
| 靜態評估 KOL 可信度 | **動態 rolling 準確率**：根據近期表現調整因子權重 |
| 只看文字 | 多模態：文字 + 語音（YouTube Whisper 轉錄）|
| 單平台 | 跨平台聚合：Threads + X + YouTube |
| 娛樂追蹤 | 嚴格量化：回測 + IC + 因子穩健性測試 |

### 市場上的空白

banini-tracker 是目前最接近這個方向的開源實作，但它：
- 只追蹤**一個 KOL**
- 沒有**因子化框架**（只做通知，沒有回測）
- 沒有**動態信任度調整**
- 只有**單平台**（Facebook）

本研究的定位是：將 banini-tracker 的單點實作**泛化成可擴展的多 KOL 量化研究框架**。

### 為什麼現在是好時機

- LLM 的中文理解能力在 2025–2026 年已足夠強，過去這樣的系統做不到
- 台灣財經 KOL 生態在 Threads/YouTube 有大量歷史資料可回溯
- Alpha101 因子框架提供現成的整合接口，降低回測工程難度
