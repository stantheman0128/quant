# 專題提案：基於多情境壓力分析的量化因子穩健性評估

## 一、研究動機

### 問題背景
量化交易策略的核心挑戰不是「找到報酬最高的策略」，而是「確保策略在極端環境下不會崩潰」。2008 金融海嘯、2020 COVID 崩盤、2022 升息風暴，每一次都有大量回測績效漂亮的策略在實戰中歸零。

### 現有方法的不足
1. **歷史回測**：只測試已發生的事件，無法涵蓋未來可能的新型態危機
2. **傳統 Monte Carlo**：從已知統計分佈（如 GBM、GARCH）隨機抽樣，但這些分佈在結構性衝擊（regime change）發生時會失效
3. **因子研究**：現有文獻大量關注因子的報酬預測能力，但較少系統性研究因子在壓力環境下的行為變化

### 關鍵缺口
目前沒有人做過：
- 在**因子層級**（而非投組層級）做系統性的壓力穩健性評估
- 用 **AI 生成具因果邏輯的壓力情境**來補充傳統統計模擬的盲區
- 建立**因子穩健性的量化評分框架**

---

## 二、研究問題

> 在多種壓力情境下，哪些量化因子具有「條件穩健性」——即壓力越大、表現反而越好或至少不顯著衰退？能否建立一套系統性的評估方法來識別這類因子？

```
│  ├── 二次項係數 > 0 → 凸性（穩健/反脆弱）        │

└───────────────────────────────────────────────┘
```

### 3.2 因子選取策略

從 Alpha101（Kakushadze, 2016）中選取 5-8 個覆蓋不同類型的代表性因子：

| 類型 | 代表因子 | 金融邏輯 |
|------|---------|---------|
| 動量（Momentum） | Alpha#12 等 | 追漲殺跌的趨勢信號 |
| 反轉（Mean Reversion） | Alpha#6 等 | 超跌反彈的回歸信號 |
| 波動率（Volatility） | Alpha#40 等 | 波動放大/收斂的信號 |
| 量價關係（Volume-Price） | Alpha#52 等 | 成交量驗證價格的信號 |
| 日內結構（Intraday） | Alpha#101 等 | 開盤到收盤的價格效率 |

選取標準：覆蓋不同因子類型、公式可在日頻資料上實作、有明確的金融解釋。

### 3.3 壓力情境生成（技術核心）

#### 第一類：歷史事件回放
直接使用真實歷史資料，標記危機期間，比較因子在危機期 vs 非危機期的表現差異。

#### 第二類：AI 輔助的假設性情境
```
步驟一：LLM 生成壓力劇本（自然語言）
  輸入：「生成一個影響科技股的地緣政治壓力情境」
  輸出：「半導體禁令升級 → 台積電供應鏈中斷 → 科技股連鎖下跌」

步驟二：參數化（人工定義 + 規則引擎）
  ├── 衝擊幅度：-10%, -15%, -20%, -25%, -30%
  ├── 持續時間：2 週, 1 個月, 3 個月
  ├── 傳染速度：緩慢, 中等, 恐慌
  └── 恢復模式：V 型, U 型, L 型

步驟三：合成時序資料生成
  ├── 基於歷史波動率結構 + 壓力參數疊加
  ├── 保留 GARCH 特性（波動叢聚）
  └── 加入指定的衝擊形態

步驟四：品質驗證
  ├── 規則過濾：單日跌幅 > -15% 的情境標記為極端
  ├── 統計檢查：合成資料的分佈特徵是否合理
  └── 人工審核：隨機抽樣 10% 做合理性判斷
```

### 3.4 條件穩健性評分

基於 Taleb & Douady (2013) 的脆弱性啟發式（fragility heuristic），定義因子穩健性指標：

**核心概念：凸性分析**

對每個因子 α，將其在不同壓力強度 σ 下的表現 R(σ) 做二次迴歸：

```
R(σ) = a + b·σ + c·σ²

其中：
  σ = 壓力強度（市場跌幅的絕對值）
  R = 該因子在該壓力下的 Sharpe Ratio
  c = 二次項係數（凸性指標）

判斷：
  c > 0 → 凸性（反脆弱）：壓力越大表現越好
  c ≈ 0 → 線性（穩健）：壓力不影響表現
  c < 0 → 凹性（脆弱）：壓力越大表現越差
```

**額外指標：**
- 壓力存活率：在所有壓力情境中 Sharpe > 0 的比例
- 最大壓力回撤：所有情境中最差的單次表現
- 穩健性離散度：不同情境下表現的標準差

## 四、技術實作

### 4.1 技術棧
| 項目 | 選擇 | 理由 |
|------|------|------|
| 語言 | Python 3.11+ | 量化金融標準語言 |
| 因子計算 | pandas + NumPy | 向量化運算，不依賴外部回測框架 |
| 回測邏輯 | 自建（排序 → 分組 → 多空） | 完全掌控邏輯，避免黑箱 |
| 壓力情境生成 | Claude API / GPT API | 生成因果一致的自然語言劇本 |
| 合成資料 | 自建（基於 GARCH + 衝擊疊加） | 保留統計特性的壓力模擬 |
| 並行計算 | multiprocessing / joblib | 加速大規模回測 |
| 視覺化 | matplotlib + seaborn | 熱力圖、績效曲線、因子比較 |
| 版本控制 | Git | 所有程式碼和實驗記錄 |

### 4.2 資料來源
- **美股日頻資料**：Yahoo Finance API（免費，S&P 500 成分股）
- **時間範圍**：2005-2025（涵蓋多次危機）
- **欄位**：Open, High, Low, Close, Volume, Adj Close
