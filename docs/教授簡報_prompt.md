## 專題題目

**基於 AI 輔助壓力情境生成的量化因子穩健性自動化評估框架**

英文：*An Automated Evaluation Framework for Quantitative Factor Robustness via AI-Assisted Stress Scenario Generation*

## 一句話定義

設計一套計算框架，能自動對量化因子做多層壓力驗證（歷史回測 → Walk-Forward → AI 生成壓力情境 + Monte Carlo 變體），產出穩健性評分，組裝出在熊市仍有效的策略。

## 研究問題

> 在各種金融危機情境下，哪些量化因子具有「條件穩健性」——即壓力越大、表現反而不崩潰甚至更好？能否用 AI 生成的壓力情境來補充歷史壓力測試的不足？

## 核心技術貢獻（三個，每個獨立成章）

### 貢獻 1：NL → 金融時序的跨模態轉換 Pipeline（核心 novelty）

這是一個「text-to-financial-time-series」問題，類似 text-to-image（DALL-E）但應用在金融領域。

**核心概念**：目前要測試投資策略能不能撐過金融危機，只能用歷史上真的發生過的幾次危機（2008、2020、2022）。但歷史危機就那幾次——如果未來來一種「從沒發生過的危機」呢？我的方法是：用 AI 寫出各種危機劇本，然後把劇本「翻譯」成真的股價數據，拿去測試策略。

**三段式 pipeline**：

**Step 1 — LLM 結構化（讓 AI 用固定格式講話）**

用 Claude API 生成危機劇本，但不是自由發揮的文字，而是要求 AI 用固定的 JSON schema 回答。

例如：「聯準會意外升息 200bp，科技股崩盤，金融股受益，持續 2 個月，V 型反彈」會被轉成：
```json
{
  "觸發事件": "聯準會意外升息 200bp",
  "受影響板塊": {
    "科技股": { "方向": "下跌", "嚴重程度": "高" },
    "金融股": { "方向": "上漲", "嚴重程度": "中" }
  },
  "整體市場": { "方向": "下跌", "嚴重程度": "高" },
  "持續時間": "中等",
  "恢復模式": "V型反彈"
}
```
→ 就像把一篇作文變成一張填好的表格，讓電腦能讀。

**Step 2 — 規則引擎參數化（把「形容詞」變成「數字」）**

我自己設計一套翻譯規則，把 JSON 中的定性描述映射為定量參數：
- 「嚴重程度：高」→ 跌幅 -20%~-30%（隨機取值）
- 「持續時間：中等」→ 20-40 個交易日
- 「V型反彈」→ 恢復速度係數 λ=0.7（指數衰減）

這個中間層是**可解釋的**——每一步翻譯規則都是透明的，不是黑盒。這套「翻譯字典」的設計就是我的 personal contribution。

**Step 3 — GARCH + 衝擊疊加生成合成時序（用數字畫出假的股價曲線）**

1. 用歷史資料估計 GARCH(1,1) 模型，生成「正常波動」的基底股價
2. 在指定日期疊加衝擊：衝擊曲線 f(t) = A·exp(-λt)（第一天跌最多，之後指數衰減恢復）
3. 不同板塊套用不同方向的衝擊（科技股跌、金融股漲）
4. 輸出：500 支股票的逐日 OHLCV 合成數據

**Monte Carlo 變體**：因為 Step 2 的數字是範圍不是定值，同一個「聯準會升息」故事可以跑 45 種參數變體（不同跌幅、不同天數、不同恢復速度）。策略要在大部分變體中都表現好，才算穩健。

**文獻定位（為什麼沒人做過）**：

現有工作分三塊，互不重疊：
- **Soleimani (2025)**：做 LLM → 風險指標（VaR），但**跳過時序生成**——從情境直接算出一個數字，不生成逐日股價
- **Woo et al. (2025)**：做 NL → 時序（diffusion model），但是**黑盒**——中間過程不可解釋
- **GAN/VAE 系列（72 篇論文）**：做合成金融資料，但**無情境語意**——從歷史分佈學習，不帶因果邏輯

我的方法填補了「**有情境語意 + 可解釋的中間層 + 生成逐日時序**」這個空白位置。三個領域的人各做各的，我把它們用一個透明的規則引擎接在一起。

### 貢獻 2：基於凸性分析的穩健性評分演算法

將 Taleb & Douady (2013) 的脆弱性理論工程化：
- 對每個因子，收集其在所有壓力情境下的表現
- 做二次迴歸：R(σ) = a + b·σ + c·σ²
- c > 0 = 反脆弱（壓力下更好）、c ≈ 0 = 穩健、c < 0 = 脆弱
- 加上多維指標：存活率、最差回撤、跨情境離散度
- Bootstrap 信賴區間

### 貢獻 3：端到端自動化評估 Pipeline（系統設計）

因子計算 → 回測引擎 → Walk-Forward 驗證 → 壓力測試 → 穩健性評分 → 策略組裝。全部用 Python 自建（pandas + NumPy），不依賴外部回測框架。模組化架構、統一資料介面。

## 方法概覽（系統架構圖）

```
輸入：6 個量化因子（Alpha101 / 經典因子）+ S&P 500 歷史資料
  ↓
[Layer 1] 因子計算引擎 → 計算所有因子值（自建，pandas 向量化）
  ↓
[Layer 2] 回測引擎 → 排序→五分位→多空回測 → 基準 Sharpe
  ↓
[Layer 3] Walk-Forward 驗證 → 滾動視窗，檢測過擬合
  ↓
[Layer 4] 壓力測試引擎
  ├── 歷史事件：2008 金融海嘯、2020 COVID、2022 升息（6 個危機）
  └── AI 生成情境：LLM 劇本 → 規則引擎 → GARCH+衝擊 → Monte Carlo 變體（~150 情境）
  ↓
[Layer 5] 穩健性評分 → 凸性分析 + 多維指標
  ↓
輸出：因子穩健性排名 + 熱力圖 + 最終策略（穩健因子加權組合）
```

## 驗證方式

1. **歷史回放驗證**：用 2008 金融海嘯的參數生成合成資料，跟真實 2008 比較相似度
2. **策略一致性**：同一因子在合成 2008 和真實 2008 的表現排名是否一致
3. **Walk-Forward**：樣本外 Sharpe 為正即通過
4. **單元測試**：每個模組都有 pytest 測試
